# 저장소 이력

KT AIVLE 4·5차 팀 프로젝트의 코드를 바탕으로 김건우가 운영하는 독립 포트폴리오 저장소입니다.
팀 저장소의 브랜치와 변경 이력에서 출발했으며, 개인 공개본에 실행 설정·문서·검증 체계를 정리했습니다.

- 2025년 12월: 팀 프로젝트 서비스 구현 및 AWS 배포 환경 구성
- 2026년 10월: 개인 포트폴리오 정리, 코드 개선과 회귀 테스트 확장
- 원본과 공개본 커밋 대응: [history-commit-map.tsv](history-commit-map.tsv)
- 개인 역할과 근거: [CONTRIBUTIONS.md](CONTRIBUTIONS.md)

현재 코드·문서는 개인 공개본에서 발전시키며, 원본 팀 조직의 저장소와 별도로 관리합니다.
