# 제3자 자료 확인

- 원본 프로젝트 LICENSE는 발견되지 않았습니다. 팀 프로젝트 자체에 임의로 오픈소스 라이선스를 부여하지 않았습니다.
- Java·Spring·AWS SDK 등 의존성은 Gradle로 받으며 라이브러리 소스나 실행 JAR을 이 저장소에 복사하지 않았습니다. 재배포 시 각 라이선스·저작권 고지를 유지해야 합니다.
- 실제 실행 의존성 119개의 라이선스 메타데이터는 `dependency-licenses.json`에 기록했습니다. MySQL Connector/J의 GPLv2 및 Universal FOSS Exception, Hibernate의 LGPL, Logback·Jakarta의 복수 라이선스 조건 등이 포함됩니다. 의존성 사용 선언을 해당 바이너리 재배포의 포괄적인 허가로 해석하지 않습니다. 실행 JAR·컨테이너 배포 시 적용되는 조건을 확인해야 합니다.
- `ion-java:1.0.2`는 캐시된 POM에 라이선스가 없어 공식 해당 버전의 [LICENSE](https://raw.githubusercontent.com/amazon-ion/ion-java/v1.0.2/LICENSE)를 별도로 확인했습니다(Apache-2.0).
- 저장소에 포함된 Gradle Wrapper JAR은 공식 Gradle 9.2.1 Wrapper SHA-256과 일치합니다. Gradle은 Apache-2.0 프로젝트입니다. 참고: https://github.com/gradle/gradle 및 https://services.gradle.org/distributions/gradle-9.2.1-wrapper.jar.sha256
- 초기 데이터는 테스트용 문자열·예시 이메일과 Picsum 외부 이미지 URL을 사용합니다. 외부 이미지 파일을 다운로드·재배포하지 않았습니다.
- 원본 README의 외부 첨부 이미지 2개는 과거 기록에 남아 있습니다. 새 기본 README는 이미지 없이 작성했습니다.
- 교육기관·팀, 외부 이미지·샘플 데이터와 작성자 이름·이메일 공개 허용 여부에 대해 소유자가 2026-10-27에 허용된다고 답했습니다. 이 확인은 외부 제공자의 약관이나 별도 라이선스를 대체하지 않습니다.
- 클라우드 리소스 식별자·배포 경로와 원본 서버 주소는 모든 복사 기록에서 예시값으로 치환했습니다. 이들은 유효 자격증명을 제공하지 않으며, 원본 인프라에 대한 사용 권한을 의미하지 않습니다.
