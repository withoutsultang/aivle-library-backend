# 출처와 의존성 고지

본 저장소는 KT AIVLE 4·5차 팀 프로젝트를 바탕으로 한 개인 포트폴리오입니다. 원본 작성자와 변경 이력을 보존하고, 개인 기여는 [CONTRIBUTIONS.md](CONTRIBUTIONS.md)에 구분했습니다.

- 제3자 라이브러리의 라이선스·저작권 조건은 각 패키지를 따릅니다. [의존성 메타데이터](dependency-licenses.json)를 함께 보관합니다.
- 라이브러리·런타임 바이너리 재배포 시 해당 버전의 라이선스 원문과 고지를 확인합니다. 메타데이터 목록은 라이선스 원문을 대신하지 않습니다.
- 교육자료·실제 클라우드 계정 정보·서비스 비밀키를 새 문서에 재배포하지 않습니다. 배너는 이 공개본을 위해 작성한 SVG입니다.
- 외부 이미지·서비스·샘플 데이터는 해당 제공자의 조건을 따릅니다. 브랜드 이름은 후원·인증을 의미하지 않습니다.
- 팀 프로젝트 전체에 새 오픈소스 라이선스를 임의로 부여하지 않았습니다.

교육기관·팀 자료와 작성자 정보의 공개 범위는 저장소 소유자가 2026-10-27에 확인한 범위를 기준으로 정리했습니다.
